\# EmailTrace



EmailTrace is an email-forensics platform designed to analyze simulated or authorized email evidence and help investigators identify suspicious email characteristics.



\## Features



\- Sender and recipient analysis

\- Email header analysis

\- Received-path reconstruction

\- IP and domain information

\- Email content analysis

\- Investigation timeline

\- Evidence and forensic reporting



\## Tech Stack



\- Frontend: HTML, CSS, JavaScript

\- Backend: Python / Flask

\- Database: MySQL

\- Version Control: Git \& GitHub
